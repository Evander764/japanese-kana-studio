# 日语起步

一个从零基础开始学日语的网站：[在线使用](https://evander764.github.io/japanese-starter/)。第 00 课学习五十音，第 01—14 课学习基础句型。也可以下载仓库，双击 [index.html](index.html) 离线使用，无需安装。

## 从第 00 课开始

课程路线按第 00—14 课排列。第 00 课连接已有的平假名、片假名卡片和识读练习；第 01—14 课是句型课程。五十音学习可以随时继续，不用全部掌握才能进入下一课。原有课程编号和浏览器中的学习记录保持不变。

网站分为首页、课程目录和单课页面。首页显示下一课；完成第 00 课后，首页会转向第 01 课。五十音仍可从课程目录回看，浏览器前进后退和课程直达链接也可使用。后续新增课程界面请遵循[课程界面设计基线](docs/interface-system.md)。

首页可试听第 01 课的第一句。试听、课程、单词本和假名练习共用“正常 1× / 慢速 0.78×”语速选择；切换一次后，其他朗读位置也会同步。想暂时核对读音，可用页面右上角的罗马音开关。

第 01—14 课各有一个单词本，每课 16—18 个词，共 238 张词卡（221 个不重复的词）。可按章节查看日语写法、罗马字、中文释义并听离线发音；每轮练习对未标记学会的词各考一次读音和词义。熟悉的词可点“标为已经学会”，以后练习会跳过；重复出现在不同章节的同一个词共用这项标记，也可随时恢复练习。单词进度与其他学习记录一起保存在本机，并包含在导出、导入和重置中。

词卡和词汇练习把“听合成读音”与“查看辞典音调”分开。辞典音调默认收起，展开后显示东京式高低图及来源；`0 型`表示词内不降调，`n 型`表示第 n 拍后降调。若降调在最后一拍之后，单独读这个词时可能听不出。小「ゃ / ゅ / ょ」与前一个字合为一拍；促音「っ」、长音「ー」各算一拍。合成 MP3 未按这些图逐词校准，不能拿它验证音调；句子中的助词、语速、语气也会影响实际声调。

“互动课程”已有十四节原创入门课：自我介绍、指示词与所属、地点、时间、日常动作、移动、存在句、形容词、过去时、て形连接、愿望、比较、许可与禁止、邀请与计划。每节有三句带发音的例句和八道练习题，涵盖看句选义、补全、排序、读音及听力。看句选义和读音题可边做边听；补全、排序题提交后可听完整句子；听力题先听后看文字。错题可自愿定点再练。课程不锁关，按自己的进度选课。选项和词块可按数字键，输入读音与进入下一题可按 Enter。完整路线和教材参考见 [学习路线](docs/learning-roadmap.md)。

假名和课程都区分“自动学会”和“确认学会”。前者由答题表现自动判定，表现回落会恢复“学习中”；后者由自己手动决定，退出自动复习，随时可以恢复。假名可在卡片详情或进度表操作，课程可在课程卡片操作。两类状态都包含在进度导出、导入和重置中。

## 使用

1. 点击首页“开始第 00 课”，依次认识平假名和片假名，再用识读练习巩固；准备好后点“学完了，继续第 01 课”，以后首页会显示下一课。
2. 也可以点击“无限混合练习”，或选择“混合学习”专区。题目会穿插平假名、片假名、原有词例，以及「コーヒーをのむ」这样的假名组合短语。短语把片假名外来语和平假名助词、动词连起来，答题后可查看意思、读法和节拍提示。前六项连续引入，此后大约每三题加入一项新内容，其间穿插复习。全部 242 项见过后仍可无限练习，薄弱项目出现得更频繁。进度条、累计题数和连续答对数会保存在浏览器中。
3. 也可以选择平假名或片假名专区，点击首页“直接开始自测”，从当前专区的全部项目抽题，无需先逐张查看卡片。首次提交后，该项目自动变为“学习中”。
4. 也可以在“五十音表”中按行点开卡片查看读音和发音，或点击卡片下方的按钮直接标记“已学／未学”。手动标记不会删除已有答题记录。
5. 在“识读练习”中可切换“无限混合学习”“全部项目”或“只练已学项目”。遇到不会读的题，可以在提交前点“听当前发音”；卡片自测里也有“听发音”按钮，播放不会显示罗马字，输入框会继续保持焦点。输入罗马字后按 **Enter**：答对会自动显示下一题；答错会显示答案，再按 Enter 继续。上一题的读音与词义保留在题目下方，可点“重听”或按 **Alt+P** 回听。学习卡片中的自测答对后也会自动进入下一个未学项目。
6. 在“学习进度”查看薄弱项、确认学会或恢复复习，并导出、导入或重置本机记录。“罗马字转换”可自由对照两种字形。

页面右上角的“显示罗马音／隐藏罗马音”可以随时切换假名卡片、单词本、例句和读音提示中的罗马音。选择会保存在本机，也会随学习记录导出和导入。

## 内容和判题

- 每种字形有 46 个清音、25 个浊音及半浊音、36 个拗音；另有 19 个促音和长音词例，以及 9 个平假名和片假名组合短语，合计 242 个独立学习项目。
- 主要字形和读音参考[日本国际交流基金《いろどり》假名教材](https://www.irodori.jpf.go.jp/assets/data/Kana_all.pdf)。包括教材标注为少见的「ぢゃ／ぢゅ／ぢょ」。
- 单词音调中的 138 个词按[《いろどり》官方词汇表](https://www.irodori.jpf.go.jp/resources.html)核对，49 个词按[东京大学 OJAD](https://www.gavo.t.u-tokyo.ac.jp/ojad/eng/pages/home)的词形标注核对；余下 34 个活用词形由本地 Open JTalk 推定，在词卡中逐个标为“推定”。这些是东京式音调参考，不代表所有地区或说话者都只使用一种读法。生成过程保存在 `tools/build_pitch_data.py`；官方词表文件和模型文件不进入仓库。
- 判题接受常见罗马字变体，例如 `shi/si`、`chi/ti`、`tsu/tu`。`ji`、`zu` 等同音异形输入在题目中按目标字形判定；自由转换会给出候选提示。
- 促音、长音用词例学习。自由转换采用确定性规则，无法替代完整日语输入法；对有多种正字法的词，以学习卡片的示例为准。

## 进度与发音

每项只用最近 10 次答题计算平滑正确率 `A = (答对数 + 1) / (题数 + 2)`；最近 5 次答对的用时中位数与目标时间比较，得出慢速比例 `S`（0～1）。抽题难度为 `D = 0.7 × (1 − A) + 0.3 × S`，抽题权重为 `1 + 5D`。单个假名、拗音、原有词例和组合短语的目标分别是 4、6、10、16 秒。复习抽题避免最近两项重复，并优先补抽太久未出现的项目。最近 8 次至少答对 7 次、最近两次都答对且用时达标时，状态为“熟练”。“无限”表示练习不会结束；新内容来自固定的 242 项题库。

进度存于浏览器的 `localStorage`。换浏览器、清理网站数据或某些浏览器改变本地文件权限后，记录可能不再可见，建议定期导出 JSON 备份。导入会覆盖当前记录。所有进度都只留在本机。

所有假名、28 个单语或混合短语都附有本地 MP3，直接打开网页也能离线朗读，不依赖系统日语语音。平假名和对应的片假名共用一段读音，共 126 段假名音频和 9 段组合短语音频；十四节课程另有 392 段例句、词卡和练习题发音。网页点击“听发音／听整句”时读取对应的本地 MP3；明确选择“正常 1×”即按文件原速播放，需要跟读时选择“慢速 0.78×”，浏览器会尽量保持音高。语速选择会保存在本机。假名单字和拗音会自动读两遍，词汇、短语和整句只读一遍。短语卡片另有中文释义、助词和动词结构、节拍提示；练习答错或查看答案后会显示这些提示，答对自动跳题时仍可回听上一题。

目前的 285 段词汇相关音频改由本机 Windows 日语语音重新录制，以 Microsoft Ayumi 为主；「コップ」「ケーキ」「きっぷ」等五段难辨的短词采用 Microsoft Sayaka。词汇页和课程中的词卡、词汇题同步使用新版音频。原有假名、短语和句子音频仍由本地 [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M) 与 [Qwen3-TTS](https://github.com/QwenLM/Qwen3-TTS) 合成。网页直接播放打包的 MP3，离线使用不要求系统安装这些声音或模型。`audio/manifest.json`、`audio/phrase-manifest.json` 和 `audio/course-manifest.json` 记录每段音频的文本、引擎、音色、时长和 SHA-256。合成读音供认读和跟读使用，不能代替母语者对音调与自然语流的示范。若音频文件丢失，网页会明确报错。

新版词汇音频逐段保存哈希与时长，并由独立的本地日语识别模型筛查。对「つくえ」「ペン」「りょこう」单独调整了语速；对仍易混淆的短词比较了另一套女声。自动识别遇到数字、同音汉字和极短词会误报，因此筛查结果不是母语者语音评审，也不能证明合成语音符合辞典音调。

## 开发验证

需要 Node.js 运行测试；学习网页本身不需要 Node.js。

```powershell
node --test tests/*.test.js
node tests/browser-smoke.js
```

第二条命令使用本机 Chrome 的无界面模式，检查桌面与手机断点、首次自测、练习和转换流程。若 Chrome 不在默认路径，可用 `CHROME_PATH` 环境变量指定其可执行文件。
发布后可设置 `PAGE_URL=https://evander764.github.io/japanese-starter/`，用同一条命令对公开站点做回归检查。

普通学习和播放音频无需安装模型。重新生成词汇音频时，`tools/generate_sapi_words.ps1` 使用本机已安装的日语 SAPI 声音和 `ffmpeg`，在仓库外暂存 285 段 MP3 及检查点；`tools/audit_qwen_sentences.py --words` 用独立的本地日语识别模型筛查；`tools/assemble_word_voice.py` 可把逐段核对过的备用音色并入；`tools/publish_word_voice.py` 逐段校验文本、时长、哈希后发布并更新两个清单。重新合成全部音频的旧流程由 `tools/generate_kokoro_refresh.py`、`tools/generate_qwen_audio.py` 和 `tools/publish_audio_rebuild.py` 保留；`tools/generate_voicevox_words.py` 保留作支持逐拍音调设定的本地备选方案，模型与词典都放在仓库外。
