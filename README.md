# 假名练习室

一个从五十音识读延伸到基础句型的日语学习网站：[在线使用](https://evander764.github.io/japanese-kana-studio/)。也可以下载仓库，双击 [index.html](index.html) 离线使用，无需安装。

## 新增：互动课程

“互动课程”已有八节原创入门课：自我介绍、指示词与所属、地点、时间、日常动作、移动、存在句和形容词。每节先看语法提示和带发音的词卡，再完成五种不同题型；听力题先听后看文字，错题可自愿定点再练。课程不锁关，按自己的进度选课。选项和词块可按数字键，输入读音与进入下一题可按 Enter。完整路线和教材参考见 [学习路线](docs/learning-roadmap.md)。

假名和课程都区分“自动学会”和“确认学会”。前者由答题表现自动判定，表现回落会恢复“学习中”；后者由自己手动决定，退出自动复习，随时可以恢复。假名可在卡片详情或进度表操作，课程可在课程卡片操作。两类状态都包含在进度导出、导入和重置中。

## 使用

1. 点击首页“开始无限混合学习”，或选择“混合学习”专区。题目会穿插平假名、片假名、原有词例，以及「コーヒーをのむ」这样的假名组合短语。短语把片假名外来语和平假名助词、动词连起来，答题后可查看意思、读法和节拍提示。前六项连续引入，此后大约每三题加入一项新内容，其间穿插复习。全部 242 项见过后仍可无限练习，薄弱项目出现得更频繁。进度条、累计题数和连续答对数会保存在浏览器中。
2. 也可以选择平假名或片假名专区，点击首页“直接开始自测”，从当前专区的全部项目抽题，无需先逐张查看卡片。首次提交后，该项目自动变为“学习中”。
3. 也可以在“认识假名”中按行点开卡片查看读音和发音，或点击卡片下方的按钮直接标记“已学／未学”。手动标记不会删除已有答题记录。
4. 在“识读练习”中可切换“无限混合学习”“全部项目”或“只练已学项目”。遇到不会读的题，可以在提交前点“听当前发音”；卡片自测里也有“听发音”按钮，播放不会显示罗马字，输入框会继续保持焦点。输入罗马字后按 **Enter**：答对会自动显示下一题；答错会显示答案，再按 Enter 继续。上一题的读音与词义保留在题目下方，可点“重听”或按 **Alt+P** 回听。学习卡片中的自测答对后也会自动进入下一个未学项目。
5. 在“学习进度”查看薄弱项、确认学会或恢复复习，并导出、导入或重置本机记录。“罗马字转换”可自由对照两种字形。

## 内容和判题

- 每种字形有 46 个清音、25 个浊音及半浊音、36 个拗音；另有 19 个促音和长音词例，以及 9 个平假名和片假名组合短语，合计 242 个独立学习项目。
- 主要字形和读音参考[日本国际交流基金《いろどり》假名教材](https://www.irodori.jpf.go.jp/assets/data/Kana_all.pdf)。包括教材标注为少见的「ぢゃ／ぢゅ／ぢょ」。
- 判题接受常见罗马字变体，例如 `shi/si`、`chi/ti`、`tsu/tu`。`ji`、`zu` 等同音异形输入在题目中按目标字形判定；自由转换会给出候选提示。
- 促音、长音用词例学习。自由转换采用确定性规则，无法替代完整日语输入法；对有多种正字法的词，以学习卡片的示例为准。

## 进度与发音

每项只用最近 10 次答题计算平滑正确率 `A = (答对数 + 1) / (题数 + 2)`；最近 5 次答对的用时中位数与目标时间比较，得出慢速比例 `S`（0～1）。抽题难度为 `D = 0.7 × (1 − A) + 0.3 × S`，抽题权重为 `1 + 5D`。单个假名、拗音、原有词例和组合短语的目标分别是 4、6、10、16 秒。复习抽题避免最近两项重复，并优先补抽太久未出现的项目。最近 8 次至少答对 7 次、最近两次都答对且用时达标时，状态为“熟练”。“无限”表示练习不会结束；新内容来自固定的 242 项题库。

进度存于浏览器的 `localStorage`。换浏览器、清理网站数据或某些浏览器改变本地文件权限后，记录可能不再可见，建议定期导出 JSON 备份。导入会覆盖当前记录。所有进度都只留在本机。

所有假名、28 个单语或混合短语都附有本地 MP3，直接打开网页也能离线朗读，不依赖系统日语语音。平假名和对应的片假名共用一段读音，共 126 段假名音频和 9 段组合短语音频；八节课程另有 56 段例句、词卡与听力发音。音频做过响度归一化；默认以 0.78 倍慢速播放，假名和拗音会自动读两遍，词例读一遍。朗读区的速度按钮可切换正常语速或慢速，偏好会保存在本机。短语卡片另有中文释义、助词和动词结构、节拍提示；练习答错或查看答案后会显示这些提示，答对自动跳题时仍可回听上一题。

音频由 [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M) 的日语合成语音生成，未包含模型文件；`audio/manifest.json`、`audio/phrase-manifest.json` 和 `audio/course-manifest.json` 记录假名、短语及课程音频的输入、音素和时长。这些是辅助认读的合成读音，不能代替母语者示范的音调和自然语流。`tools/normalize_audio.py` 可用 FFmpeg 将音频统一到合适响度；`tools/generate_audio.py` 和 `tools/generate_course_audio.py` 也会在生成时应用相同的响度处理。若音频文件丢失，网页会明确报错。

## 开发验证

需要 Node.js 运行测试；学习网页本身不需要 Node.js。

```powershell
node --test tests/*.test.js
node tests/browser-smoke.js
```

第二条命令使用本机 Chrome 的无界面模式，检查桌面与手机断点、首次自测、练习和转换流程。若 Chrome 不在默认路径，可用 `CHROME_PATH` 环境变量指定其可执行文件。
发布后可设置 `PAGE_URL=https://evander764.github.io/japanese-kana-studio/`，用同一条命令对公开站点做回归检查。

`tools/generate_audio.py` 是可选的音频制作脚本，需要另行准备 Kokoro 日语 ONNX 模型、`jf_alpha.bin`、`kokoro-onnx-ja` 与 `ffmpeg`。普通学习和播放音频无需运行此脚本。仅重生成混合短语时使用 `--only-mixed-examples`，清单会写入单独的 `audio/phrase-manifest.json`。
