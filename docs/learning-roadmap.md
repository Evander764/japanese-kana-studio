# 从五十音开始的学习路线

本站独立编写练习与例句。路线参考人民教育出版社《新版中日交流标准日本语》初级“分单元逐步推进”的结构，以及日本国际交流基金《いろどり》Starter A1 的入门学习目标与初级语法项目；不转载教材课文、对话、图片或习题。

## 已制作：第 00—14 课

| 节次 | 学习任务 | 实际练习 |
| --- | --- | --- |
| 00 | 五十音入门：认识平假名与片假名 | 按行看字卡、听发音，并用识读练习巩固 |
| 01 | 介绍自己：身份句与否定 | 听懂职业、选择助词、组句、输入读音 |
| 02 | 这本书是谁的：指示词与所属 | 区分距离、用「の」表示所属 |
| 03 | 车站在哪里：地点与疑问 | 问地点、理解这里／那里／远处 |
| 04 | 现在几点：时间的起点和终点 | 区分「から」「まで」，读时间词 |
| 05 | 喝茶与读书：动作的对象 | 用「を」和「ません」说日常动作 |
| 06 | 乘巴士去公园：方向和交通工具 | 区分方向助词「へ」与工具「で」 |
| 07 | 房间里有只猫：存在句 | 区分「います」「あります」 |
| 08 | 安静的小城：形容词 | 区分 い形容词与 な形容词的基本用法 |
| 09 | 昨天做了什么：过去时 | 区分 `ました` 与 `ませんでした`，描述过去的动作 |
| 10 | 先吃早餐，再出门：て形 | 认识常用动词的て形，按顺序连接两个动作 |
| 11 | 想看动画，想要自行车：愿望 | 区分想做的 `たいです` 与想要物品的 `ほしいです` |
| 12 | 电车和巴士，选哪个：比较 | 用 `より／のほうが` 比较两个选择，辨认比较方向 |
| 13 | 这里可以拍照吗：许可与禁止 | 用 `てもいいですか` 询问许可，听懂 `てはいけません` |
| 14 | 明天一起去公园吧：邀请与计划 | 区分邀请 `ませんか` 与提议 `ましょう` |

第 00 课使用已有的五十音字卡和识读练习。第 01—14 课每节有一句带本地音频的例句、词卡发音、简明语法提示和五种不同操作：看句选义、补全句子、词块排序、输入罗马字读音、听音选义。听力题提交前不显示文字。每题只出现一次，完整练习结束即可前进；答错的题在结尾提供可选的定点复习。课程均可自由打开。

## 第 09—14 节的衔接

第 09 节在已有ます形基础上学习过去肯定与否定；第 10 节给出常用动词的て形示例，再连接先后动作。第 11—14 节分别练习愿望、比较、许可与禁止、邀请与提议。每节都有原创例句、五张词卡、五种题型、答题解释和七段本地音频；十四节共 70 道题、98 段课程音频。

第 09—14 节已经可以直接进入学习，不再作为待开发路线显示。原有八节课程与已保存进度继续有效。比较、禁止和邀请的排序题接受已列明的自然语序变体，意思与动作关系保持一致。

## 掌握与复习规则

- 假名：沿用最近 8 题至少答对 7 题、最近两题答对、最近答对用时达标的“自动学会”规则；表现回落会退回“学习中”。
- 课程：最近一次完整五题至少答对四题，且词块排序和读音输入两题均正确，标记“自动学会”；后续完整练习成绩回落会退回“学习中”。可选错题回顾不会改变完整练习的自动掌握结论。
- 手动“确认学会”：假名或课程会退出自动抽题／推荐，历史记录保留。学习者可随时“恢复自动复习”；主动打开卡片或课程仍可练习。
- 所有进度随当前 JSON 导出／导入／重置，保存在用户本机浏览器。
