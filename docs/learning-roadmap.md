# 假名之后的学习路线

本站独立编写练习与例句。路线参考人民教育出版社《新版中日交流标准日本语》初级“分单元逐步推进”的结构，以及日本国际交流基金《いろどり》Starter A1 的入门学习目标；不转载教材课文、对话、图片或习题。

## 已制作：八节可直接使用的交互课程

| 节次 | 学习任务 | 实际练习 |
| --- | --- | --- |
| 01 | 介绍自己：身份句与否定 | 听懂职业、选择助词、组句、输入读音 |
| 02 | 这本书是谁的：指示词与所属 | 区分距离、用「の」表示所属 |
| 03 | 车站在哪里：地点与疑问 | 问地点、理解这里／那里／远处 |
| 04 | 现在几点：时间的起点和终点 | 区分「から」「まで」，读时间词 |
| 05 | 喝茶与读书：动作的对象 | 用「を」和「ません」说日常动作 |
| 06 | 乘巴士去公园：方向和交通工具 | 区分方向助词「へ」与工具「で」 |
| 07 | 房间里有只猫：存在句 | 区分「います」「あります」 |
| 08 | 安静的小城：形容词 | 区分 い形容词与 な形容词的基本用法 |

每节有一句带本地音频的例句、词卡发音、两条简明语法提示和五种不同操作：看句选义、补全句子、词块排序、输入罗马字读音、听音选义。听力题提交前不显示文字。每题只出现一次，完整练习结束即可前进；答错的题在结尾提供可选的定点复习。课程均可自由打开。

## 接下来的学习任务

09. 过去发生的事：`Vました／Vませんでした`，说昨天和上周做过什么。
10. 连接动作：て形，按时间顺序说明两个动作。
11. 表达愿望：`Vたいです／Nがほしいです`，说明想做、想要。
12. 比较与选择：`より／ほうが`，比较两个交通方式或商品。
13. 许可和规则：`てもいいです／てはいけません`，表达可否做某事。
14. 邀请与计划：`ませんか／ましょう`，商量下一次出行。

09–14 目前是路线图，尚未提供互动题，界面不把它们算作已完成课程。继续制作时，每节先确定一个生活场景和可观察的任务，再补充原创例句、易混点、五种题型及本地发音，避免机械复刷同一道题。

## 掌握与复习规则

- 假名：沿用最近 8 题至少答对 7 题、最近两题答对、最近答对用时达标的“自动学会”规则；表现回落会退回“学习中”。
- 课程：最近一次完整五题至少答对四题，且词块排序和读音输入两题均正确，标记“自动学会”；后续完整练习成绩回落会退回“学习中”。可选错题回顾不会改变完整练习的自动掌握结论。
- 手动“确认学会”：假名或课程会退出自动抽题／推荐，历史记录保留。学习者可随时“恢复自动复习”；主动打开卡片或课程仍可练习。
- 所有进度随当前 JSON 导出／导入／重置，保存在用户本机浏览器。
