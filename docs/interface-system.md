# 课程界面设计基线

状态：可用的设计候选；结构和交互已在本地浏览器检查，最终审美接受由使用者判断。

## 任务与信息层级

- 读者：已经开始学日语、会反复回到网站继续学习的人，也包括第一次进入的零基础学习者。
- 主要动作：第一眼知道下一课是什么，点击后进入该课；也能切到独立的课程目录浏览 00—14。
- P0：当前推荐课、继续按钮、课程路线。P1：所选课程内容和进度状态。P2：单词本、学习记录、转换与五十音工具。
- 主要错误路径：完成五十音后仍被首页的大假名和「从五十音开始」按钮带回第 00 课。

## 视觉哲学与三种方向

核心概念是一本会记住翻到哪一页的练习册。首页右侧的大编号表示**下一课**，随着学习进度变化；它不承担假名教学。课程编号、列表和面板沿同一阅读路径连接。纸色承载阅读，深青标记学习位置，橘色只标主行动；字形教学区域保留日文字体，其他区域用中文系统无衬线。没有装饰性的樱花、假名字样或无任务的环形图。

1. 清晰基线：文字列出下一课和全部课程，保留所有入口；可用，但缺少明显的回到学习位置的线索。
2. 采用方案：大编号与继续按钮配对；首页、课程目录和单课页面彼此跳转。手机上的目录是双列课程卡，单课页面是单列内容。
3. 过载反例：首屏同时铺满五十音、进度环、所有功能卡和装饰性日文；会把第 00 课误读成永久首页。

## 持续适用的界面规则

- 首页只显示下一课的摘要和主行动。首次进入推荐第 00 课；用户在第 00 课点「学完了，继续第 01 课」后推荐第 01 课；已有句型课记录时根据课程进度推荐下一课。已完成的第 00 课仍在路线中，可随时回看。
- 页面关系固定为「首页 → 课程目录 → 单课页面」。主导航在所有页面保持同一位置；单课页面有返回目录入口。地址栏使用 `#courses`、`#lesson/00` 等路由，刷新、直接打开链接、浏览器前进后退要回到对应页面。
- 第 00 课拥有平假名、片假名和识读练习入口；这些练习不单独占据首页。已有的假名状态、句型课状态和单词状态保留。课程没有强制解锁顺序。
- 主导航只放跨课程入口：课程路线、单词本、学习进度、罗马字转换。五十音的扩展工具放在「学习工具」菜单。以后新增课程内容时，优先扩展课程列表、课程面板与对应单词本，不再给首页增加常驻教学模块。
- 课程目录的每项都保持编号、课名、简短目标与状态；当前推荐课同时用底色和边框表达，不只靠颜色。单课页面承载例句、语法、单词和练习，不改变课程进度算法。
- 手机端的全局导航横向滚动，课程目录为双列；单课页面单列呈现。按钮保留触控尺寸，页面本身不横向溢出。

## 验收边界

- 在桌面和 390 / 320 像素手机宽度检查首页、目录、单课页面与横向溢出。
- 检查从首页打开目录、从目录进入课程、返回目录、浏览器后退、刷新及直接打开课程链接。
- 检查新用户首页为 00；标记第 00 课完成后首页变为 01；刷新、导出导入和重置时进度一致。
- 结构通过不代表用户已经认可视觉气质。首个新方向仍待真人审美反馈。
